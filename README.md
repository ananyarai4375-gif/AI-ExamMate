# AI ExamMate

AI ExamMate is an AI-based study assistant that helps students analyze their study materials and prepare for exams.

## Features

- Upload study materials
- Analyze uploaded content
- Generate exam-focused questions
- Subject-based study assistance

## Tech Stack

- Python
- FastAPI
- React
- JavaScript
- AI
